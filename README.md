# Autocode – Source

Application code lives here (custom). This is the project's **default workspace** (self-contained; see
`../<pack>/engineer.agent.md` Workspaces) and in local mode the git root. The engineer persona generates
and maintains this tree against `../<pack>/spec.md`. In remote-code mode this folder is removed
and the code lives on the host named in `../remote.json`.
