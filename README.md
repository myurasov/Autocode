# Autocode web UI demo

This branch holds the demo published at https://myurasov.github.io/Autocode/: a static replica of the Autocode
web UI, filled with an invented setup (12 agents that run one person's home life and their engineering project).
Every name, number and text in it is invented. The page loads only its own files, talks to no server and keeps
nothing.

`ui.css` and `help.js` are generated from the web UI's source (`web/` on `main`): the UI's own stylesheets and
its Help text. Autocode itself is on the [`main`](https://github.com/myurasov/Autocode) branch.
