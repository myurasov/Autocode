# Autocode: For Agents <!-- omit in toc -->

Two files tell agents what they need:

- [`autocode.admin.agent.md`](autocode.admin.agent.md): for an agent working on this repository, or installing,
  checking or updating Autocode: what this repository is, and how to install Autocode.
- [`autocode.consumer.agent.md`](autocode.consumer.agent.md): for agents that use Autocode in their own projects.
  It is the source of the `autocode` skill that the Autocode plugin gives every OpenCode session (and of
  `autocode_me action=help`), so an agent with the plugin already has it.

People: start with [`README.md`](README.md); every detail is in [`reference.md`](reference.md).
